Recent reads

Updated as I go

Papers I've read recently and keep coming back to — mostly on judging, critiquing, and reasoning about model output.

ACL2026

MARCH: Multi-Agent Reinforced Check for Hallucination ↗

Splits hallucination checking across a Solver, a Proposer, and a Checker, then withholds the original answer from the Checker so it can't rubber-stamp its own reasoning. Deliberate information asymmetry as a fix for confirmation bias in LLM judges.

Li et al.
OpenReviewPreprint

Critique-Coder: Enhancing Coder Models by Critique Reinforcement Learning ↗

Trains a coder model to critique rather than only to answer, rewarding it when its judgment of a solution matches the ground-truth label. Swapping a fifth of the RL data for critique data beats RL-only baselines — and the gains carry over to general reasoning.

Ruan, Jiang, Wang, Chen
arXiv2026

Agentic Code Reasoning ↗

Asks whether agents can reason about code semantics without running it. Structured "semi-formal" prompting forces explicit premises and traced execution paths, acting as a certificate the agent can't skip steps in — with clear gains on patch equivalence and fault localisation.

OpenReviewPreprint

Meta-Evaluation Collapse: Who Judges the Judges of Judges? ↗

Argues that stacking LLM evaluators on LLM evaluators converges on internally consistent but ungrounded verdicts. Judges agree with each other while drifting away from human raters — which is the whole problem my own work is circling.

TMLR2026

Can VLMs Reason Robustly? A Neuro-Symbolic Investigation ↗

Fine-tuned VLMs score well in-distribution and fall apart under covariate shift, suggesting training doesn't actually install the reasoning rule. The fix compiles the rules into a symbolic circuit and leaves the model to do perception.

Chen, Vergari, Zhao
